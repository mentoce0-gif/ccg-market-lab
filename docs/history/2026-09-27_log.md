## 3. 確認済みの事実（2026-09-27）

- Etsy の手数料：販売手数料 6.5%、決済手数料は日本の口座で 6.0%＋$0.30、出品料 $0.20、為替 2.5%（出品と入金の通貨が違う時）。開店時に一度だけ設定料がかかる場合がある。
- Offsite Ads：新しい店は自動で参加になる。年間の売上が $10,000 未満なら止められる（Shop Manager → Settings → Offsite Ads）。止めないと、広告経由の注文に 15%。
- AI の使用：説明文に書くことが Etsy の規約で必須。
- Etsy の利用規約は、許可のない crawl・scrape を禁じている。
- Etsy API は、出品ごとの累計閲覧数しか返さない。訪問数・流入元・検索語は、管理画面の統計でしか見られない。
- Etsy API の Seller App は、条件を満たす売り手なら数分で承認されると Etsy は説明している。
- 別のアカウントで自分の店の商品を買う試験はしない（規約が「販売の操作」を禁じている）。
