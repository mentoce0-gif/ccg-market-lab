Plan your term, grade it, and see who needs help, all in one spreadsheet. The tabs are linked, so a date you set in the pacing plan flows through to due dates, the gradebook, each student's missing work, and the class dashboard.

INSTANT DIGITAL DOWNLOAD. No physical item is shipped.

WHAT'S INCLUDED
- Teacher_Command_Center_Blank.xlsx: an empty file ready for your class
- Teacher_Command_Center_Sample.xlsx: the same file filled with a fictional class, so you can explore it before you start

9 TABS
- Start Here: 5 setup steps and how the numbers are calculated
- Dashboard: class average, work turned in, students at risk, grade spread chart, turned-in vs. score chart, workload per week
- Setup: class name, the Monday your term starts, category weights, grade scale, at-risk lines
- Roster: up to 40 students
- Pacing: up to 20 units on a week-by-week timeline that colors itself
- Assignments: up to 60 assignments. Each one is due at the end of its unit unless you type a date
- Gradebook: type a score, M for missing or EX for excused. Past-due blanks can count as missing (you choose on Setup)
- Standings: each student's grade, turn-in rate and a performance index with rank and percentile, plus an optional curved grade if your school allows relative grading
- Student Report: pick a student and get a one-page summary for conferences, with every assignment marked Submitted, Missing, Excused or Not due yet

HOW THE LINKS WORK
Pacing plan > assignment due dates > gradebook knows what is due > turn-in rate, missing work and grades update > dashboard and student report show the result.

FORMAT AND LIMITS
- .xlsx file for Microsoft Excel. To use Google Sheets, upload the file to Google Drive and choose File > Save as Google Sheets.
- One class per file: up to 40 students, 60 assignments and 20 units. For more classes, make a copy of the blank file.
- The file does not use macros and does not connect to the internet. Your student data stays in your own copy.
- Grading categories: Homework, Quizzes, Tests, Projects, Participation. Set a weight to 0% if you do not use one.
- This is a planning and record-keeping tool. Check your school's grading policy before using the curved grade.

HOW THIS WAS MADE
This spreadsheet was designed and built with the help of AI tools (the layout, formulas and sample data were generated with AI and then checked by recalculation). The sample class is fictional.
