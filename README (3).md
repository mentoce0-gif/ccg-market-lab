新しい候補は、1候補1ファイルで `CAND-xx_短い名前_提出者.md` として置く。次の項目を必ず書く。

- 用事
- 原文の短い引用
- URL と、書かれた日
- 証拠区分（E1〜E4）
- 置き場と導線
- 提供物と対象外
- 価格と変動費の仮説
- 単位経済性（¥10,000 に月何件要るか）
- 48時間と14日の棄却条件
- 一度だけ変える項目
- 反対の証拠
